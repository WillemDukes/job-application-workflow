# Contributor Covenant Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our Pledge

We pledge to make participation in our project a welcoming experience for everyone.

## Enforcement

Instances of unacceptable behavior may be reported to the maintainer privately to @WillemDukes through a GitHub security advisory (Security tab > Report a vulnerability).
